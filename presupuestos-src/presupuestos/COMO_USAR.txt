COTIZADOR RENTING CORPORATIVO
=============================

Programa para armar presupuestos de alquiler de vehiculos y descargarlos en
PDF con la plantilla de la empresa.

--------------------------------------------------------------------
COMO ABRIRLO (es un solo archivo, no se instala nada)
--------------------------------------------------------------------
1) Guarda el archivo "Cotizador Renting Corporativo.html" en el Escritorio.
2) Hace doble clic. Se abre en tu navegador y ya podes usarlo.
3) Para pasarselo a un companiero: envia ese mismo archivo (por mail,
   WhatsApp, USB, etc). No necesita instalar nada.

Necesitas internet para que carguen los vehiculos y las fotos (se guardan
en la nube y se comparten con todo el equipo).

--------------------------------------------------------------------
QUE SE ABRA COMO UN PROGRAMA (ventana propia, sin barra del navegador)
--------------------------------------------------------------------
WINDOWS (con Edge o Chrome):
  - Clic derecho en el Escritorio > Nuevo > Acceso directo.
  - En "ubicacion" pega (ajusta la ruta a donde guardaste el archivo):
      msedge --app="C:\Users\TU_USUARIO\Desktop\Cotizador Renting Corporativo.html"
    (si usas Chrome, reemplaza "msedge" por "chrome")
  - Nombralo "Cotizador Renting Corporativo". Se abre en su propia
    ventana, como una aplicacion.

--------------------------------------------------------------------
COMO SE USA
--------------------------------------------------------------------
- "Nuevo presupuesto": elegis los vehiculos tocando su foto, las tarifas y
  seguros vienen precargados y los podes cambiar. Toca "Generar PDF" y descarga.
- "Catalogo y fotos": editas las tarifas base y SUBIS la foto de cada vehiculo.
  Se guarda en la base compartida para todo el equipo.
- "Configuracion": datos de la empresa que salen en la portada y pie del PDF.

--------------------------------------------------------------------
PARA DESARROLLADORES (opcional, si hay que modificar el programa)
--------------------------------------------------------------------
  npm install        (una vez)
  npm run dev        (modo desarrollo, http://localhost:5173)
  npm run build      (genera el archivo unico en dist/index.html)
